# Conteúdo do portfólio

Edite somente os arquivos desta pasta para cadastrar conteúdo repetível:

- `projects.ts`: adicione ou remova projetos no array `projects`.
- `technologies.ts`: adicione ou remova stacks no array `technologies`.
- `experiences.ts`: adicione ou remova experiências no array `experiences`.
- `certifications.ts`: adicione ou remova cursos e certificados.

Cada novo item é renderizado automaticamente pelo componente correspondente. Não é necessário duplicar JSX.

Os intervalos dos carrosséis ficam em `src/config/carousel.ts`.
